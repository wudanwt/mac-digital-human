# 平台默认数字人与背景

当前选定范围：本机 SaaS 数据库中除“丹哥”以外的 7 个数字人，以及 `background` 素材按 SHA-256 去重后的 6 张图片。用户已确认可开放给所有租户用于商业课程生成。这个授权选择仅适用于明确列出的素材；不能据此自动发布未来上传的内容。

## 使用方式

- 平台管理员显式发布一次模板。发布时校验源文件大小与 SHA-256，复制到对象存储的 `system-defaults/` 前缀；不直接公开原工作区对象，也不把媒体二进制提交到 Git。
- 登录用户在“素材中心 → 平台默认素材”按需导入。数字人会连同人物图片、母版视频、参考声音和音色配置复制到当前工作区；背景仅复制所选图片。导入后沿用现有租户隔离、课程编辑和渲染链路，原课程与原素材不变。
- 平台数字人不占用户个人数字人数量额度，但复制到工作区的文件计入存储额度；重复点击导入不会再复制。背景导入后可在课程演播厅的“工作区背景”中选择。

## 本机发布步骤

1. 先备份数据库，再部署本分支代码到当前本机 SaaS 容器，并确认启动时的 `alembic upgrade head` 成功。不要在仍运行旧代码的容器上手动变更业务数据。
2. 确认源工作区 ID 和对象存储配置与当前数据库匹配。本机核对结果：源工作区 `c2d659ecb8404797baaf08a6c9b57c4b`，7 个数字人的 21 个依赖文件与 6 张去重背景均存在且 SHA-256 校验通过。
3. 在**使用该数据库及同一对象存储配置**的 API 容器中执行（不会输出原始媒体或密钥）：

   ```bash
   python -m app.saas.system_assets_admin \
     --source-tenant c2d659ecb8404797baaf08a6c9b57c4b \
     --avatars 宁雅,小白,明明,朵朵,老白,若琳,阿曼达 \
     --all-backgrounds \
     --confirm-platform-license
   ```

4. 用另一个工作区登录，确认目录恰有 7 个数字人、6 张背景，无“丹哥”；导入一个数字人和一张背景，验证能用于课程、第二次导入不重复、无法访问原工作区私有素材。

生产迁移时必须把数据库中的模板记录和 `system-defaults/` 媒体对象作为**同一份快照**迁移；只迁移代码或只复制媒体都不能让目录可用。若生产使用全新数据库，应先制定经过校验的素材包导入流程，不能假设本机的源工作区会自动出现在群晖上。发布前还要在真实对象存储和异地 Worker 上做渲染验收。
