# 母版视频录制规范

为了让口型替换稳定，第一阶段建议把母版视频当作“数字讲师动作底片”。

## 推荐

- 1080p，25fps 或 50fps；系统最终会统一为 25fps。
- 固定机位，胸部以上。
- 正脸为主，可轻微左右转头，但不要长时间大侧脸。
- 光线稳定，嘴部无遮挡。
- 30~60 秒即可做第一轮测试。
- 自然呼吸、轻微点头、少量手势，比完全僵住更自然。
- 背景尽量简洁，避免人物嘴部附近有高频纹理或快速运动物体。

## 避免

- 手频繁挡嘴。
- 快速低头、抬头或超过约 30° 的持续侧脸。
- 强闪烁灯光。
- 视频严重压缩、过度美颜或锐化。
- 口罩、透明杯子等长时间遮挡嘴部。

## 第一轮验收素材

建议只录一条 20~30 秒测试母版，并准备一条 10~20 秒清晰中文语音。先验证：

1. 人脸检测是否稳定。
2. 嘴型是否自然。
3. 嘴周融合是否明显穿帮。
4. 推理速度和温度是否可接受。

通过后再录正式 30~60 秒模板。
