# Scripts

- `setup.sh` — bootstrap Python, upstream repos and Q8 models.
- `setup_models.py` — download an MLX variant and peripheral weights.
- `check_env.py` — check basic macOS tools.
- `check_runtime.py` — verify Python imports, repositories and model files.
- `run_avatar.sh` — CLI render launcher.
- `run_web.sh` — local Web/API launcher.
